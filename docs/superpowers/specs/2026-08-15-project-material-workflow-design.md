# 项目素材与任务执行闭环设计

## 1. 问题与根因

当前桌面端把“项目”当作任务列表容器，却没有项目首页。新建项目后只显示任务输入框，用户会被迫先创建任务。素材上传又只存在于 `tasks.input_json.source_paths`，因此素材不能在项目内先管理、复用或选择；没有附件时前端仍会创建并运行任务，后端随后将任务标记为失败。

Electron 还固定连接 `127.0.0.1:8000`，启动时只检查该端口是否返回健康响应。旧版本后端或另一个开发实例占用端口时，当前前端会错误连接到不兼容服务，从而产生 Product Event 解析错误。

## 2. 目标用户流程

```text
创建项目
-> 进入项目首页
-> 上传项目素材，或显式点击“导入示例数据”
-> 查看素材名称、类型、大小、来源和完整性摘要
-> 勾选本次任务所需素材
-> 输入任务目标并创建任务
-> 平台绑定素材快照后启动 Workforce
-> 查看智能体进度、商品图谱、合规问题、平台草稿和文件产物
-> 返回项目首页继续管理素材或创建下一项任务
```

项目创建与任务创建完全解耦。示例素材不得自动写入新项目。

## 3. 数据边界

新增 `project_materials`：每条记录属于一个项目，保存原始文件名、持久化路径、MIME、字节数、SHA-256、来源（上传或示例）、元数据和创建时间。

新增 `task_materials`：记录任务对项目素材的选择顺序。任务输入仍保存解析器需要的 `source_paths`，但该字段由平台根据 `task_materials` 投影，不再由前端提交任意本地路径。

项目素材存储在：

```text
runtime/project-materials/<project-id>/<material-id>/<file-name>
```

任务 Artifact 继续存储在 `artifacts/<task-id>/`。素材是可复用输入，Artifact 是不可变输出，两者不混用。

## 4. 平台接口

- `GET /api/projects/{project_id}`：项目详情。
- `GET /api/projects/{project_id}/materials`：素材列表。
- `POST /api/projects/{project_id}/materials`：上传一个或多个项目素材。
- `POST /api/projects/{project_id}/materials/import-example`：显式导入仓库内置示例素材。
- `GET /api/project-materials/{material_id}/download`：下载原始素材。
- `POST /api/tasks`：接收 `project_id`、`objective` 和至少一个 `material_id`；平台校验归属并建立任务绑定。
- `POST /api/tasks/{task_id}/run`：在加入后台队列前同步检查任务素材，不满足条件返回 `409`，不制造失败任务。

旧的任务附件上传接口保留兼容，但其实现必须先将文件写入项目素材库，再绑定到任务。

## 5. 桌面交互

选中项目时默认进入项目首页，不自动打开最近任务。项目首页包含：项目摘要、素材库、上传按钮、导入示例数据按钮、素材多选列表、任务目标输入和最近任务。

“创建并运行任务”只在目标非空且至少选中一项素材时可用。没有素材时显示明确的两条入口：上传素材、导入示例数据。任务工作区提供“返回项目”入口。

已有失败任务仍可查看，但其英文错误在展示层转换为中文。项目素材不因任务失败而丢失。

## 6. 示例数据

仓库提供 `examples/womenswear-us/womenswear-catalog.csv` 和说明文件。数据包含两款女装、多个颜色和尺码、完整纤维成分、洗护、原产地、制造商、价格和库存，可直接跑通目录、合规、Listing 和治理流程。导入操作由用户显式触发，并按 SHA-256 去重。

## 7. 事件与进程隔离

健康接口返回应用 ID、应用版本、Product Event 协议名称与版本。Electron 启动时分配独占空闲端口，将端口传给打包后端，并在加载页面前校验完整身份；前端通过启动 URL 获取 API 地址。这样不会再复用占用 `8000` 的旧服务。

前端对 Product Event 做运行时结构校验。协议不匹配时显示“桌面端与后端版本不兼容”，停止盲目重连；序列缺口通过重新拉取快照恢复。

## 8. 验收标准

1. 新建项目后进入项目首页，且数据库中没有自动创建任务。
2. 新项目没有自动素材；用户可上传素材或显式导入示例数据。
3. 示例导入后能看到素材元数据，重复导入不产生重复记录。
4. 未选择素材时不能创建并运行任务。
5. 任务只可绑定本项目素材，运行前同步校验素材存在且哈希一致。
6. 示例数据可完成一次真实端到端工作流并生成文件产物。
7. 从任务工作区可以返回项目首页并创建下一项任务。
8. Electron 不会连接到旧版本或其他占用固定端口的后端。
9. Product Event 不兼容会给出明确错误，不显示笼统的 JSON 解析错误。
