# Governance Review Checklist

1. Resolve the active canonical Product resources.
2. Resolve compliance results and pending Human Approval items.
3. Resolve only the Shopify/eBay draft scope requested or available.
4. Confirm Product version lineage and cross-channel SKU, material, origin, size, and claim consistency.
5. Treat blocking findings as blocked and pending confirmations as waiting for approval.
6. Create an export package only when the decision is approved and the task explicitly requests it.

The final package is a deterministic Artifact with manifest and hashes. It does not publish products.
