# Product catalog intake

Use deterministic parsers for CSV, Excel, JSON, PDF, Markdown, text, and image metadata. Preserve every original file as a source artifact. Never fabricate missing product facts. Group rows by explicit product/style identifier, keep SKU-level size and color values, and create Human Approval for conflicting authoritative fields.
